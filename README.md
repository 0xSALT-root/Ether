# Ether

Ether is a modern, privacy-focused Android web browser built on top of **GeckoView**. It integrates **WireGuard** for built-in VPN capabilities and provides a seamless media experience using **AndroidX Media3**.

## 🚀 Key Features

- **Privacy First**: Built with GeckoView for a secure and private browsing experience.
- **Integrated VPN**: High-performance VPN support via the WireGuard protocol.
- **Advanced Media**: Enhanced video playback with ExoPlayer and Media3 session support.
- **Modern Tech Stack**: Fully built with Jetpack Compose, Hilt, Room, and Coroutines.
- **Adaptive Design**: Supports phone, tablet, and foldable form factors.

## 🛠 Tech Stack

- **UI**: Jetpack Compose
- **Engine**: Mozilla GeckoView
- **VPN**: WireGuard Android SDK
- **Architecture**: MVVM / Clean Architecture
- **Dependency Injection**: Hilt
- **Database**: Room
- **Networking**: OkHttp / Retrofit
- **Media**: AndroidX Media3 (ExoPlayer)
- **Background Tasks**: WorkManager

## 🏗 Setup & Build

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Ether.git
   ```
2. Open the project in **Android Studio Ladybug (or newer)**.
3. Sync the project with Gradle.
4. Run the `:app` module on an emulator or physical device (Android 8.0+).
